# tmxh v1.2.6

## English

First public release of tmxh on GitHub.

tmxh is a command-line tool for running and tracking shell commands in tmux panes, including over SSH.

### Features

- Shell command execution in tmux panes
- Command execution tracking
- Remote operation over SSH
- AI agent integration documentation
- Debian package build support
- English and Hungarian documentation

## Magyar

A tmxh első nyilvános GitHub-kiadása.

A tmxh egy parancssori eszköz shellparancsok futtatására és követésére tmux panelekben, akár SSH-n keresztül.

### Funkciók

- Shellparancsok futtatása tmux panelekben
- Parancsvégrehajtás követése
- Távoli működés SSH-n keresztül
- AI-ügynökök integrációs dokumentációja
- Debian-csomag készítésének támogatása
- Magyar és angol nyelvű dokumentáció
